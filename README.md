# codeKaro

A full-stack roadmap learning platform built with MERN ecosystem.

## 🎯 Goal

Help developers learn technologies through structured roadmaps, track progress and build projects step by step.

## 📦 Tech Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma

## 📁 Project Structure

client/ - React Frontend

Server/ - Express Backend

docs/ - Documentation

.github/ - Github workflows
